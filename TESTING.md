# Тесты backend

Запуск: `mvn --batch-mode --no-transfer-progress verify` (JDK 17, Maven).
PostgreSQL и API-ключи не нужны: репозитории заменены Mockito, запросы Nominatim перехватывает MockRestServiceServer.

В test resources выбран Mockito subclass mock maker: текущие тесты подменяют интерфейсы и обычные классы, поэтому не нуждаются в динамическом подключении Java agent. Для будущих тестов final/static методов потребуется пересмотреть этот выбор.

- AuthControllerTest: вход, отказ при неверных данных, пустые поля, занятый логин, сохранение хеша.
- RouteControllerTest: права на удаление, отсутствующий маршрут, расстояние и владелец нового маршрута.
- GeocodingServiceTest: преобразование ответа, HTTP 500 и некорректные координаты провайдера.

Это ещё не проверки HTTP-аутентификации и реальной БД. Следующие шаги: сервисный слой и валидация, MockMvc для маршрутов и interceptor, PostgreSQL Testcontainers для запросов и ограничений.

Учебное упражнение: допиши тест одинаковых точек маршрута, затем тест невалидной широты. Первый должен пройти, второй выявит отсутствие серверной валидации. Добавь валидацию и проверь повторно весь набор.

Workflow `.github/workflows/backend-ci.yml` выполняет ту же проверку на Java 17 после push/PR. Развёртывание в нём пока отсутствует.
